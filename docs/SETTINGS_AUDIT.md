# 无患影音设置项审计（第一版）

> 范围：手机端设置页、Setting/PlayerSetting/DecodeSetting/PreloadSetting/DanmakuSetting/LiveSetting 等偏好设置类。  
> 状态：源码静态审计；部分高级音视频参数尚未追踪到最终播放器消费者，不能视为完整验收。

## 1. 设置页面结构

当前手机端设置导航由以下页面组成：

| 页面 | 主要项目 | 主要源码 |
|---|---|---|
| 设置首页 | 点播源、直播源、播放、弹幕、界面、隐私与网络、存储与备份、关于 | `SettingFragment` |
| 播放设置 | 播放画面尺寸、解码、广告拦截、渲染方式、画面缩放、后台播放、缓冲、预加载、UA | `SettingPlayerFragment` |
| 解码设置 | AAC 优先、Tunnel、音频/视频解码优先、Dolby Vision 输出策略、音频直通 | `SettingDecodeFragment` |
| 预加载 | 总开关、下一集预加载、线程、缓存大小、预加载时长 | `SettingPreloadFragment` |
| 弹幕 | API、加载开关、自动匹配、Spider 优先 | `SettingDanmakuFragment` |
| 界面 | 进入详情自动播放、豆瓣精选首页、继续观看、壁纸 | `SettingUiFragment` |

| 存储与备份 | 缓存清理、备份、恢复 | `SettingStorageFragment` |
| 关于 | 版本号 | `SettingAboutFragment` |

## 3. 播放设置（PlayerSetting.java）

- 播放引擎：`getEngine()` 当前直接返回 `ENGINE_EXO`；手机端设置页隐藏引擎选择行。虽然保留 IJK 常量及兼容方法，但不能据此声称当前手机版可切换 IJK。
- 进入详情自动播放：默认 false。
- 渲染方式：Surface 默认；可在 Surface / Texture 间切换。开启解码 Tunnel 时会强制回到 Surface。
- 画面尺寸：默认索引 2，范围 0–3。
- 画面缩放：默认索引 0，范围 0–4。
- 后台播放：默认值 2，范围 0–2；0 关闭、1 后台播放、2 后台播放并支持画中画。
- 缓冲档位：范围 1–10；缺省读取值经 clamp 后至少为 1。
- Libass 字幕渲染：默认 true。
- 播放器调试开关：默认 false。

注意：`putEngine()` 将传入值写成固定的 Exo 引擎值；它不是可用的引擎切换实现。

## 4. 解码设置（DecodeSetting.java）

- 音频直通：默认 true，读取时兼容旧键 `audio_pass_through`。
- 音频优先：默认 false，兼容旧键。
- 视频优先：默认 false，兼容旧键。
- Dolby Vision 输出策略：默认 AUTO，非法值回退 AUTO。
- AAC 优先：默认 false，兼容旧键。
- Tunnel：读取新键并兼容旧键；启用时若当前 Exo 渲染方式为 Texture，会强制改为 Surface。

这些设置会影响设备解码器选择及音频输出。必须在具体设备上验证，不应把“开关可点”当成播放兼容性已验证。

## 5. 预加载设置（PreloadSetting.java）

| 项目 | 默认值 | 约束 |
|---|---:|---|
| 预加载总开关 | false | 开/关 |
| 下一集预加载 | false | 开/关 |
| 并发线程 | 1 | 1–10 |
| 预加载缓存大小 | 128 MB | 128–4096 MB，步进 128 MB |
| 预加载时长 | 120 秒 | 20–120 秒，步进 10 秒 |

发现一个值得核对的实现细节：类中虽然定义了暂停预加载策略常量和归一化方法，但 `getPausePreloadPolicy()` 当前固定返回 ALWAYS，没有读取偏好值。需要追踪是否为有意固定策略，还是遗留的未完成设置。

## 6. 弹幕、字幕、直播及音视频效果

- 弹幕设置包含 API 地址、加载开关、自动匹配及 Spider 优先策略；当加载关闭或 API 地址为空时，界面会隐藏下游选项。
- 字幕设置支持来源样式（原始/系统/自定义）、字号、位置、透明度、描边、阴影、副字幕轨道等；字幕搜索 Token 可优先使用用户 Token，否则回退到 Vod Config 的 `assrt`。
- 直播设置包含画面缩放、超时换源秒数和自定义 EPG 地址；超时 0 表示跟随直播源配置，EPG 为空表示使用源自带地址。
- 音频效果包括预设/自定义均衡、稳定度、对白增强、增益、前级、声道模式、中心声道增益、平衡及响度相关选项。
- 视频效果包括自然/自定义预设以及饱和度、对比度、亮度、锐度、阴影、Gamma、色相和色温。
- 倍速设置范围 0.1x–5.0x，普通播放默认 1.0x，长按倍速默认 2.0x；支持跳过静音。

以上高级音视频选项还需继续追踪到播放器效果链、设备能力和设置 UI，确认哪些选项对当前 Media3 构建实际生效。

## 7. 隐私、备份与网络行为

- 无痕模式默认关闭；需逐项确认观看历史、搜索历史、收藏、崩溃日志等写入点是否遵循该开关。
- DoH 选择来自当前 VodConfig 的 DoH 列表；用户选择后同时设置 OkHttp DNS 并写入本地偏好。
- 崩溃日志通过本地 CrashLog 读取并允许复制；本地保存目录、容量上限、清理策略仍需审计。
- 缓存清理会清理 Glide 内存缓存和应用缓存。
- 备份/恢复使用 BackupManager；恢复成功后重新加载 Vod、Live 和壁纸配置。
- 备份/恢复当前仍通过 PermissionUtil 请求文件访问；需结合 Android 14 真机验证是否可改用系统文件选择器。

## 8. 初步发现与后续动作

1. 手机端播放器引擎已经固定为 Exo；应清理 UI 中误导性的引擎可选印象，但保留必要的兼容接口前先查引用。
2. 预加载暂停策略读取函数固定返回 ALWAYS；需核实其消费者与设计意图。
3. `fast_mirror`、`keyword`、`hot` 等偏好项需全仓检索引用，确认是否因更新器移除或旧 UI 改版而失去消费者。
4. 无痕模式需要覆盖所有数据写入路径，而不只是某个历史页面。
5. DoH、UA、广告拦截开关必须与网络调用链对应，说明它们的作用范围。
6. 高级音视频设置需确认 Media3 真实消费者和设备差异，避免保留无效选项。
7. 所有设置页必须与无患影音的月白/青灰/淡青绿视觉系统一致，特别检查仍使用旧 `GlassAlertDialogBuilder` 的弹窗。
8. 以上为静态审计结论；未完成项不作为功能承诺。
